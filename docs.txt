# When wraps
⠀
All commands must be in a when wrap. They are marked with the
blocks @f[Source Code Pro]when()@f and @f[Source Code Pro]endWhen()@f
⠀
##All when events##
⠀
- onInit — runs when the ball is created
- onHitBlock — runs when the ball hits a block
- onHitAny — runs when the ball hits a block or a wall
- onTick — runs every game tick
- on1Second — runs every second
- on2Seconds — runs every 2 seconds
- on6Seconds — runs every 6 seconds
⠀
##Example usage##
⠀
@f[Source Code Pro]when(onInit)@f
@f[Source Code Pro]setRotationStyle(all around)@f
@f[Source Code Pro]endWhen(onInit)@f
@f[Source Code Pro]when(onHitBlock)@f
@f[Source Code Pro]turn(10)@f
@f[Source Code Pro]endWhen(onHitBlock)@f
Lets the ball spin visually on initialization, and rotates 10°
clockwise when it hits a block.
⠀
# ⠀
# Commands
⠀
Inside when wraps, standard commands are actions the ball does.
See **List of commands** for all usable commands. Commands
without parameters do not require parentheses. e.g.
@f[Source Code Pro]stopAllSounds()@f can be expressed simply as @f[Source Code Pro]stopAllSounds@f.
⠀
##Using parameters##
⠀
Standard commands can use parameters, shown with parenthesis.
e.g. @f[Source Code Pro]turn(10)@f turns the sprite 10°
clockwise, denoted with the parameter 10.
⠀
**Multiple parameters**
⠀
Commands with multiple parameters are seperated with commas.
e.g. @f[Source Code Pro]goToPos(-100,10)@f has the inputs -100 and 10.
⠀
# ⠀
# Reporters
⠀
Reporters are variable values that can be used in command
parameters. They are denoted with curly brackets. Reporters
cannot have parameters.
⠀
Example usage: @f[Source Code Pro]turn({mouseX})@f uses the cursor's X position in
the turn command's parameter.
⠀
##List of reporters##
⠀
- xPosition — The ball's X position
- yPosition — The ball's Y position
- direction — The ball's direction in degrees
- xStretch — How stretched the ball is on the X axis
- yStretch — How stretched the ball is on the Y axis
- tintColor — The ball's tint color as a hex code
- isVisible — Whether the ball is visible or not
- layer — The ball's layer position
- size — The ball's size
- pitchEffect — Pitch modifier for the ball's sounds
- volume — How loud the ball plays sounds
- error — Returns an error
- touchingMousePointer — True if the ball is touching the cursor
- spaceKeyPressed — True if the space key is pressed
- mouseDown — True if left-click is pressed
- mouseX — The cursor's X position
- mouseY — The cursor's Y position
- timer — The in-game timer
- daysSince2000 — Returns how many days since the year 2000
- true — Returns true
- false — Returns false
- pi — Returns the constant pi
- e — Returns the constant e
- Infinity — returns Infinity
- FPS — returns the framerate
- stageColor — returns the background color in hex code
⠀
##Variables##
⠀
Reporters can also be variables in the code. They can either
be global variables or local variables for the ball.
